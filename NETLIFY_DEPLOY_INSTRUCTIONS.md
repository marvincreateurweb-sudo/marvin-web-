# 🚀 DÉPLOIEMENT NETLIFY - Instructions Simples

## Fichiers à créer sur votre ordinateur :

### 1. Créez un dossier "marvin-portfolio" sur votre bureau

### 2. Dans ce dossier, créez la structure suivante :

```
marvin-portfolio/
├── build/
│   ├── index.html
│   ├── asset-manifest.json
│   └── static/
│       ├── css/
│       └── js/
```

### 3. Les fichiers seront fournis dans les prochains messages

## Déploiement sur Netlify :

1. Allez sur https://netlify.com
2. Créez un compte gratuit
3. Glissez-déposez le dossier "build" dans la zone de déploiement
4. Votre site sera en ligne immédiatement !

## URL personnalisée :

1. Dans Netlify, allez dans "Site settings"
2. Cliquez "Change site name" 
3. Tapez "marvin-createurweb"
4. Votre URL sera : https://marvin-createurweb.netlify.app

Plus tard, vous pourrez acheter createurweb.com et utiliser marvin.createurweb.com
