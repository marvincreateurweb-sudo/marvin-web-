# 🚀 Marvin Créateur Web - Site Premium

Site vitrine premium orienté conversion pour Marvin Créateur Web, spécialisé dans la création de sites web pour PME locales à Embrun et les Hautes-Alpes.

## ✨ Fonctionnalités

### Pages principales
- **Accueil** : Hero avec proposition de valeur forte + processus en 3 étapes
- **Offres** : 3 packages clairs avec tarifs (Starter 1490€, Business 2990€, Premium 5490€)  
- **Projets** : Portfolio avec études de cas détaillées (problème → solution → résultats)
- **Contact** : Formulaire de commande optimisé pour la conversion

### Optimisations
- ⚡ **Performance** : Images optimisées, lazy loading, Core Web Vitals
- 🎯 **SEO** : Métadonnées complètes, Schema.org, sitemap
- 📱 **Responsive** : Design adaptatif mobile-first
- ♿ **Accessibilité** : Contraste AA, navigation clavier, ARIA labels
- 🔥 **Conversion** : CTAs optimisés, preuves sociales, urgence

## 🛠️ Stack technique

- **Framework** : Next.js 14 (App Router)
- **Styling** : Tailwind CSS
- **Language** : TypeScript
- **Icons** : Lucide React
- **SEO** : next-seo
- **Images** : Next.js Image optimization

## 🚀 Installation locale

```bash
# Cloner le projet
git clone [URL_REPO]
cd marvin-site

# Installer les dépendances
npm install
# ou
yarn install

# Lancer en développement
npm run dev
# ou  
yarn dev

# Ouvrir http://localhost:3000
```

## 📦 Déploiement

### Option 1 : Vercel (Recommandé)

1. Push sur GitHub
2. Connecter le repo à Vercel
3. Déploiement automatique à chaque push

```bash
# Build de production
npm run build

# Démarrer en production
npm start
```

### Option 2 : Netlify

1. Build du projet : `npm run build`
2. Upload du dossier `.next` et `public`
3. Configuration Netlify pour Next.js

### Variables d'environnement

Créer un fichier `.env.local` :

```env
NEXT_PUBLIC_SITE_URL=https://marvin.createurweb.com
NEXT_PUBLIC_CONTACT_EMAIL=marvin.createurweb@gmail.com
NEXT_PUBLIC_PHONE=0770061075
```
